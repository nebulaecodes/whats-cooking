# 🍲 What's Cooking?

A fun and simple recipe search app built with **React** and the **Spoonacular API**.  
Search for recipes based on ingredients and get beautiful card results with working recipe links.

---

## 🌟 Features

- 🔍 Live search by ingredient (e.g. "chicken", "tofu", "spinach")
- 🍽️ View recipes with image, title, and a direct "View Recipe" button
- ❌ No results message and loading indicator
- 📱 Fully responsive layout (mobile-friendly!)
- 🧠 Built with functional components and hooks
